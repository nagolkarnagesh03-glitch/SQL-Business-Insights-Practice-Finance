# SQL-Business-Insights-Practice-Finance

Project Overview

This repository contains 50+ SQL queries solved on a Sales & Finance dataset to practice real-world Data Analyst scenarios.

The objective of this project is to strengthen SQL skills by solving business-focused questions related to:

Revenue Analysis

Regional Performance
